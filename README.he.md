# nodebb-plugin-post-follow

מעקב אחר **פוסט בודד** במקום אחר נושא שלם, עם התראה רק כשהפוסט הזה נערך.

## איך זה עובד

- מוסיף את האפשרות **"עקוב אחר פוסט זה"** לתפריט שלוש הנקודות של כל פוסט. לאחר המעקב האפשרות הופכת ל**"הפסק מעקב אחר פוסט זה"**.
- כשתוכן של פוסט במעקב נערך, כל העוקבים מקבלים התראה שמובילה ישירות לפוסט.
- העורך עצמו לא מקבל התראה, וגם לא עוקבים שאין להם עוד הרשאת קריאה לנושא.
- נתוני המעקב נמחקים כשפוסט נמחק לצמיתות.

בניגוד לצפייה בנושא, לא תקבל התראות על תגובות או על עריכות של פוסטים אחרים בנושא.

### יחס לצפייה בנושא

ליבת NodeBB כבר שולחת התראת עריכה לכל מי שצופה בנושא כולו. כדי למנוע כפילויות, התוסף מדלג על משתמשים ש:

- צופים בנושא **וגם**
- סוג ההתראה של הליבה "כאשר פוסט נערך בנושא שאני צופה בו" מופעל אצלם.

משתמש שצופה בנושא אבל כיבה את סוג ההתראה הזה, או שאינו צופה בנושא כלל, ימשיך לקבל התראות מהתוסף על פוסטים שהוא עוקב אחריהם במפורש. כך אפשר לקבל "כל התגובות בנושא, ובנוסף עריכות של פוסט אחד".

## התקנה

```bash
npm install nodebb-plugin-post-follow
```

או מתוך עותק מקומי:

```bash
cd /path/to/nodebb
npm install /path/to/nodebb-plugin-post-follow
```

לאחר מכן יש להפעיל את התוסף בלוח הניהול (הרחבות ← תוספים) ולבנות מחדש/להפעיל מחדש את NodeBB.

## תאימות

נכתב עבור NodeBB 4.x (נבדק מול קוד גרסה 4.16).

## שפות

כלולות `en-GB` ו-`he`. שפות אחרות חוזרות לאנגלית.
